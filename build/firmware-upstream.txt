# Firmware for network adapters, taken from arkos4clone's system
# (rootfs/dArkOS/usr/lib/firmware) next to the kernel modules that ask for it.
# Debian's firmware packages come first; these fill in what Debian does not
# carry (the AIC8800 dongles, for one) and never replace a Debian file.
# One name per line, as in that folder; * matches as in a shell. The build
# checks out exactly these, so a name that matches nothing costs nothing.
