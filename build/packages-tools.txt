# The security toolset, baked into the image. Each is installed on its own,
# and a package the Debian arm64 archive does not carry is skipped with a
# warning rather than stopping the build (the names here are the Debian
# names, which sometimes differ from Kali's). These are the light tools; the
# heavy ones (Metasploit, exploitdb) are installed on first online boot by
# rk-tools, to keep the flashed image small.
#
# They are for testing networks and machines that are yours, or that you
# have been asked to test.
